## 📖 Narrative Context & Lore
The Temporal Loom is failing. Unresolved logic and rogue anomalies threaten to unravel the Sacred Timeline. God Loki is holding the multiversal branches together at the End of Time, but he requires elite architects to patch the vulnerabilities. 

Participants must navigate the TVA interface, review the timeline of Nexus Events (the hackathon schedule), and make a critical choice: **Register as a variant to save the timeline, or face immediate pruning by the Void.**

## ✨ Key Features

*   **Cinematic Preloader & Typography:** A heavy, glitch-animated boot sequence that establishes the brutalist, retro-digital aesthetic before revealing the main interface.
*   **The Sacred Timeline (Horizontal Scroll):** A pinned, horizontally scrolling schedule track detailing the event phases (Nexus Events). Features interactive "TemPad" modals triggered by hover/click states.
*   **The Temporal Archives:** A dynamic "Hall of Fame" dossier system featuring custom SVG folder icons, interactive scanning radar animations, and detailed modal overlays for "Employee of All Time" records.
*   **Magnetic Section Snapping:** Custom GSAP implementation that smoothly locks the viewport to critical narrative sections while preserving unhindered horizontal scrolling capabilities.
*   **High-Stakes Dual-Choice CTA:** An interactive registration terminal. Accepting the directive redirects to the official intake form. Refusing triggers a catastrophic "Pruning" easter egg sequence (screen shake, Miss Minutes dialogue, and simulated timeline wipe).
*   **Global CRT Aesthetics:** Persistent, z-indexed CRT scanlines, shadow vignettes, and randomized opacity/brightness glitches applied globally to simulate an analog monitor viewing experience.
